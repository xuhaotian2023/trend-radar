# 光溯 GUANGSU · 视频热点捕捉与分析平台

五大视频平台热点聚合 · AI 未来热点预测 · AI 剪辑解构教学 · AI 运镜编排台。

## 快速开始

```bash
# 方式一：带真实实时数据（推荐）
node server.js          # 或 npm start
# 打开 http://127.0.0.1:8787/

# 方式二：直接双击 index.html
# 页面仍可完整使用，但热榜为内置演示数据（浏览器跨域限制无法直连平台接口）
```

环境变量：`PORT`（默认 8787）、`CACHE_MS`（默认 60000）。

## 数据来源与真实性说明

本项目对数据等级**如实标注**，页面徽标与页脚会明确区分：

| 平台 | 数据等级 | 来源 |
|---|---|---|
| 抖音 | **真实实时** | `server.js` 服务端代理抓取平台公开热榜 |
| 哔哩哔哩 | **真实实时** | 同上（`api.bilibili.com` 公开接口） |
| 微博 | **真实实时** | 同上 |
| 快手 | 演示数据 | 无公开热榜接口 |
| 小红书 | 演示数据 | 无公开热榜接口 |
| 视频号 | 演示数据 | 无公开接口 |

- 为什么必须走服务端代理：上述接口**不返回 CORS 响应头**，浏览器内直接 `fetch` 会被同源策略拦截。
- 合规原则：只读取各平台**公开可见**的热榜列表；不登录、不绕过权限、不抓取用户数据；带 60 秒内存缓存与并发合并，避免给源站造成压力；不落库、不转售。
- 未启动 `server.js` 时，`assets/live.js` 会**静默降级**为演示数据，页面不会报错。

### AI 能力的边界（避免误解）

- **AI 未来热点预测**：基于热度动量、饱和度反压、类目生命周期、时段节律的**启发式推演**，用于演示预测能力，**非平台官方预测结果**。
- **AI 运镜编排台**：**本地规则引擎** + 流行手法库匹配（无网络依赖），非大模型生成。

## 功能模块

### 1. 热点星图
五大平台 + 当日热点共六个可拖动分支节点，连线每帧实时派生；点击节点进入平台完整分析。

### 2. AI 未来热点预测（星图内）
- 未来 12 小时逐小时热度推演（预测曲线 + 悬停查看数值）
- 潜力榜：上行空间 + 置信度综合排序，标注爆发窗口
- 四类洞察：最快爆发 / 上行空间最大 / 信号最明确 / 类目倾向
- 选中话题给出推演依据与投放策略建议

### 3. AI 剪辑解构台
导入视频自动拆解剪辑步骤，映射剪映专业版**免费功能**；含剪映界面高保真模拟、多轨时间轴（支持单独点选素材 / 特效 / 转场）与分镜级解构报告。

### 4. AI 运镜编排台
输入文字描述 → 本地规则引擎匹配当下流行拍摄手法 → 输出：

- **3D 火柴人预演**：cyan 火柴人=演员、橙色火柴人=摄影师（带机身与镜头）、半透明视锥=镜头视野范围；可自由旋转 / 缩放 / 平移视角，支持俯视 / 正面 / 侧面 / 近景预设
- **手法教学**：运镜 / 构图 / 光效 / 转场 / 节奏五族，含难度、器材、运动方式、实拍步骤与避坑要点
- **分镜脚本**：景别 + 时长 + 运动方式 + 拍摄要点
- **场景与时间建议**：光线条件、最佳时段、选择理由
- **器材清单**：手机可实现的低成本方案

手法库刻意排除过时套路（如炫技式无意义环绕、全程三脚架死镜头、廉价推拉变焦），收录弧形环绕、手持跟随、甩镜转场、变速节奏、实景霓虹补光等当下在用拍法。

## 目录结构

```

  cinematography.js  运镜手法库 / 场景库 / 景别库 / 器材库
  orchestrator.js    运镜编排规则引擎

  features.js        预测与运镜台的装配层
  app.js             主交互层（路由 / 星图 / 解构台）
  charts.js / gs-ui.js / gs-fx.js
_shared/js/          内置离线库（three / echarts / tailwind / motion）
```

## 部署

- **纯静态托管**（GitHub Pages 等）：可直接部署，热榜将回退为演示数据。
- **带真实数据**：需在支持 Node 的环境运行 `server.js`（如 VPS、Render、Railway），并把域名指向该服务。

## 注意

`index.html` 与 `video-hotspot-radar.html` 内容必须保持一致，修改后请同步两份。
